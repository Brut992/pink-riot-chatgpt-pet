## Public copy

Only explicitly allowlisted artwork, accepted raster sources, previews, viewer and rewritten documentation are included. Private progress files, raw logs, generation manifests, rejected candidates, local paths and original working archives are excluded. Image metadata is stripped while decoded RGBA frames remain identical. No third-party references are published.

All publishable files, metadata, inline viewer code, JSON and repository history are scanned before publication. GitHub-generated public noreply author identities are retained as Git metadata; no personal email address is included in project files. No credentials are required by the local viewer. There are no third-party scripts, trackers or remote runtime requests.

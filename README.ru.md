# Pink Riot — анимированный питомец ChatGPT

![Утверждённый оригинальный дизайн Pink Riot](assets/pink-riot-master-design.png)

**Анимированная аниме-панк героиня для ChatGPT Pets, полностью созданная с использованием ChatGPT.** Codex применялся для сборки ассетов и технических проверок. В репозитории реальные файлы работающего питомца, а не макет.

## Установка

1. В ChatGPT откройте **Settings → Personalization → Pet → Select pet → Upload pet**, если функция доступна в вашем аккаунте.
2. Скачайте `Pink-Riot-web-upload.webp` или PNG-вариант.
3. Загрузите **один** файл; расширенный v2-атлас не подходит для стандартной веб-формы.
4. Выберите Pink Riot. Автор уже проверил импорт и работу питомца в ChatGPT.

## Содержимое

- `Pink-Riot-web-upload.webp` / `.png` — атлас 1536 × 1872 для веб-загрузки.
- `spritesheet.webp`, `spritesheet-v2.png`, `pet.json` — расширенный v2-пакет 1536 × 2288, включая направления взгляда.
- `previews/` — настоящие GIF и WebP всех девяти анимаций и взглядов.
- `preview.html` — интерактивный просмотр локально после скачивания файлов.
- `contact-sheet.png`, `look-directions.png` — обзор кадров и 16 направлений.
- `sources/frames/`, `sources/references/`, `sources/prompts/` — растровые исходники, мастер-дизайн и инструкции генерации.

Всего **57 кадров основных анимаций и 16 направлений взгляда**. Полупрозрачные контуры сохранены, бирюзовый ореол очищен в исходных RGBA-кадрах. Промежуточные направления взгляда местами визуально различаются незначительно. Исходники растровые, не PSD/Live2D/3D-риг.
